# QueueLess Nepal

QueueLess Nepal is a digital queue and token management system designed to reduce unnecessary physical waiting in hospitals, banks, government offices, colleges, and other service-based organizations.

The system allows users to view queue status, generate digital tokens, and track their turn. Staff and admins can manage organizations, services, counters, and queue flow through a web-based system.

## Tech Stack

- Frontend: HTML, CSS, JavaScript

- Database: PostgreSQL
- Admin Panel: Django Admin
- PWA: Planned for public user side

## Main Features

- Organization registration and management
- Service and counter setup
- Role-based user management
- Digital token foundation
- Django admin support
- Public-user focused PWA plan

## Project Goal

The main goal of QueueLess Nepal is to make queue management simple, transparent, and organized by helping users reduce physical waiting and allowing organizations to manage queues digitally.
